# strategy-research-lab

A research tool that finds trade ideas, prices in all costs, scores each idea from 0 to 100 and reports through a chat bot and a dashboard. 100 strategy variants compete in paper trading; real orders always stay manual.

## Highlights
- Cost-aware scoring of every idea
- Strict paper-first release gate (minimum duration, trade count and positive expectancy)
- 748 tests at ~99.9 % coverage, one `make check` quality gate
